**v2 改訂案（作成スキルの再作成指令を反映）**
```
「迷うことは、場所を知ることの最初の形である」
—— 冒頭に「雨の夜の外国の街で迷う」記憶を置く。
傘を忘れ、見知らぬ路地で雨に打たれ、焦りの中で交差点を二度間違える。
しかしその恐怖の中で、体がじわじわと街を覚えていく——角のにおい、雨音の反響、電柱の傾き。
帰れるようになった道は、地図で知っている道よりも確かに「自分のもの」だった。
GPSの指示に従えば決して迷わない。だが迷わなければ、その街は体のものにはならない。
『地図は「どこにいるか」を教えてくれるが、「そこにいること」を教えてはくれない』と締めくくる。
```
