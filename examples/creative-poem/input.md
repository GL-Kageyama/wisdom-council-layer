# サンプル入力：詩『昨日の郵便局』

**v1 初案**
```
郵便局は、昨日しか扱わない。
引出しの中では、配達されなかった手紙が
消印の時刻のまま眠っている。

消印はまだ温かく、宛先の名前は
とっくに変わってしまった誰かのものだ。
それでも局員は、蝋で封をし直す。
変わってしまった住所に、まだ待っている人が
いるかもしれないと思うから。

閉店の灯を消すとき、局員は一通だけ
誰にも届かない手紙を書く。
宛先はない。けれど今夜は
世界のどこかで、誰かが待っている気がする。
```

局は昨日しか扱わない。

消印は生ぬるい。宛名の住所は
いまは誰かの背中が暮らす場所だ。
局員は封をしない。
折り目のまま、元の場所に戻すだけ。

閉店後、局員は宛名欄が空の一通を
受付に置いて帰る。翌朝、それは消えている。

──郵便は、一度も出されなかった手紙から
始まるのだ。
