# サンプル入力：詩『重力を結わえる人』

```
朝、私は部屋の重力を結わえて、
窓辺の陽が差す場所に吊るす。
誰かの一日が、少し軽くなりますようにと。

昼、言葉がふと浮きすぎる人に、
肩にのしかかった昨日をほどいてやる。
ほどかれた夜の重さは、夕方には虹になって消える。

人は私の仕事を、奇妙で無意味だと言う。
けれど、誰も自分が重力を背負って生きていることを、
本当は知らないだけだ。

夜、私はほどいた重力を、また明日のために結わえる。
そうして世界は、昨日より少しだけ軽いままで、
今日を始める。
```
