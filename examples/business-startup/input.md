# サンプル入力：スタートアップ企画

**v1 初案**
```
■ 事業名: FOODSIGN（フードサイン）
■ 事業概要: 地域のベーカリー・弁当店・惣菜店が、閉店間際の売れ残り商品をアプリに登録し、消費者が最大70%オフで受け取りに行く食品ロス削減アプリ。店舗は廃棄を減らし、消費者は安く食事を手に入れられる。
■ ターゲット: 20〜40代の消費者、都心部の小売食品店舗
■ 収益モデル: 取引手数料10%＋店舗向け有料掲載（月額1万円）
■ 提供機能: 近隣の割引商品を地図検索／プッシュ通知で入荷通知／クーポン決済
■ 強み: 食品ロス削減という社会的価値（SDGs）を帯びたブランディング
■ 課題: 消費者向け割引アプリ市場は激戦。店舗側の登録・在庫更新の手間が大きい。
```

**v2 改訂案（作成スキルの再作成指令を反映）**
```
■ 事業名: FOODSIGN（フードサイン）— v2改訂版
■ 事業概要: 小売食品店舗（ベーカリー・精肉・惣菜）の「売り切れロス」を、レジAPI連携＋IoT重量センサーで自動取得し、廃棄予測データと受け渡し物流を一体提供するB2B在庫シグナル基盤へピボット。
■ 差別化: 消費者向け割引競争の正面から外れる。「廃棄の場」ではなく「売り切れから得られるシグナル」を商品化する。消費者向けには受け取り機能のみ残し、店舗側の在庫登録運用負担はゼロ（自動取得）。
■ 収益モデル（3本柱）:
  1) 食品メーカー向け廃棄予測データライセンス（月額固定・リカーリング）
  2) 寄付・廃棄処理業者向け共同物流プラットフォーム手数料
  3) 賞味期限設定最適化コンサル（年額契約）
■ 先行優位: ベーカリー・精肉という垂直領域に特化し、POS/重量センサーの既存店舗への導入実績で参入障壁を築く。
■ v1からの変更点: 消費者CACへの依存を脱し、B2Bリカーリング収益で事業の安定性とスケールを確保。差別化の焦点を「割引」から「廃棄の予測と転換」へ移した。
```
