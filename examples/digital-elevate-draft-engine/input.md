## 概要

**複数の全く異なった draft を統合して、一段高い成果物を生むエンジン。**

AIが一発で出す「平均的な良い答え」を超えるために、**DIVERGE（発散）→ SYNTHESIZE（統合）** の2段構えを取る。

- **DIVERGE**: 8種のクリエイターエージェント × 温度 0.7 で独立草案を生成（designer / differentiator / futurist / humanist / implementer / storyteller / strategist / visionary）。
- **SYNTHESIZE（核心）**: 全草案を読み、エージェント間の矛盾を解決する推理（Reconcile, temp 0.7）→ 解決済み推理だけを読む最終化（Finalize, temp 0.0）。
- 「統合が単発生成を上回る」は**設計目標であり、未実証の命題**。
- `synthesize()` は外部草案も受け付ける（人間の専門家の分析、別モデルの出力、過去の成果物）。

## 主要な設計要素（評価者が参照した内容）

- **エージェント正本**: `agents/{name}.md`（1エージェント=1ファイル）。エンジン起動時に読み込み、frontmatter の `name` をエージェント名、本文をシステムプロンプトに。
- **最強の主張枠**: 各草案末尾に必ず「最強の主張」1セクション。「反論されそうな点」は付けない——草案に弱点を先読みさせると自由な論述が萎縮するため、反論検出は統合段階の reconciler が引き受ける。
- **完全性ガード（broken output → regenerate）**: 打ち切り/不完全は再生成（最大3回）、直らなければ明示的失敗。
- **成果物のファイル逐次保存**: 空ファイル先作成→生成中に逐次追記（on_chunk）。打ち切りで再生成するときはファイルを空に戻してから再開。
- **推理の完全性は長さ基準（最小30字）**: 実測で6104字の完全な推理が終端記号チェックで再生成ループに落ちた反省から修正。
- **5軸評価器**: quality 0.25 / logic 0.20 / creativity 0.20 / value 0.25 / risk 0.10。リスク軸は「正直なリスク開示ほど低評価」という評価バイアスを構造として修正。
- **計測装置（compare）**: `--runs N` で反復集計（平均 overall・標準偏差・勝率）、`--baseline best-of-n` で帰無仮説比較、`--no-strong-claim` で断言枠アブレーション。
- **生成エンジン**: sdk（Anthropic SDK 直呼び）/ claude-code（呼び出しごとに `claude -p` 独立起動、温度はシステムプロンプト内の指示文で近似）。
- **テスト**: 70件通過（engine 37 / compare 13 / client 9 / evaluator 10 ほか）。
- **ファサード skill**: オーケストレーションは Python エンジン側にあり、skill は `main.py` を起動して結果を報告するだけ。エンジンをバイパスしてサブエージェントを直接統合するのはダウングレード。

## 統合優位性の実測（examples/knowledge-search/measurement.md, 2026-08-08, n=1）

| 対象 | overall | quality | logic | creativity | value | risk |
|---|---|---|---|---|---|---|
| 素の生成（単発） | **0.758** | 0.85 | 0.80 | 0.85 | 0.80 | 0.85 |
| ELEVATE | **0.755** | 0.85 | 0.75 | 0.95 | 0.75 | 0.85 |
| 差（ELEVATE−素の生成） | **-0.003** | 0.00 | -0.05 | +0.10 | -0.05 | 0.00 |

- **誠実な開示**: n=1 は統計的に無意味。差 -0.003 はノイズの範囲内で、このデータは「統合の優位性」を実証するものではない。
- 観察された傾向: ELEVATE は creativity が明確に高い（+0.10）が、logic・value がやや低い（-0.05）。統合成果物（elevated.md）は「組織の記憶層／ゾンビ知識／0件を心臓に置く設計」という単発生成にない枠組みへ再構成された独自性の代償と読める。
- 制約の自己開示: コストは単発生成の約10回分の API 呼び出し。claude-code エンジンの温度はプロンプト近似で数値再現性なし。評価は同系モデルによるため完全な独立評価ではない。
