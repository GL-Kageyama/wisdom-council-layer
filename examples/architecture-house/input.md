# サンプル入力：個人邸設計（建築）

**v1 初案**
```
■ 敷地：標高差2.5mの南斜面。敷地中央に樹齢150年のコナラが一本立つ。
■ 計画：「樹を中心に住まいを環状に取り巻く」個人邸。
　・寝室・浴室・書斎・食堂を樹の周囲に配し、それぞれを「朝・昼・夕」の光に向ける。
　・樹は屋根を貫き、構造の中心として建物を支える。
　・室内はオーク材と土壁で仕上げ、樹の足元に小さな中庭を設ける。
■ 問題点：屋根は平らで樹の落水線を傷める。構造は「樹が支える」と記すのみで荷重経路が不明。
　動線は廊下が行き止まりになり何度も引き返す。斜面は無視され、べた基礎で均してしまう。
　光の計画は「朝・昼・夕」と述べるだけで、断面に落ちていない。
```

**v2 改訂案（作成スキルの再作成指令を反映）**
```
■ 改訂の骨格：地形への応答・動線・構造の三点を再構成。
　・斜面に沿って住まいを半層ずつ降りるスプリットレベルにする。北の入口から南の水辺まで、
　　各翼が半層ずつ地形を踏む。
　・動線は樹を一周する一本の連続スパイラルに統合。行き止まり廊下を全廃し、
　　「樹に戻る」ことを常に強制する回遊動線にする。
　・構造は樹を中心に等間隔に並ぶ10組のオーク柱列と、柱から梁を落とす「垂下梁」で構成。
　　樹は五本目の柱として中央を支える。
　・屋根は樹の落水線から逃げる折れ板にし、樹側へは雨水を流さない。
■ 残る問題点：空間の物語が曖昧で「なぜこの順に部屋を巡るのか」が説明できない。
　光がまだ季節に応答しない。材料の選択が言葉のままで、経年が未検討。
```
改訂点: v1報告の指令（荷重経路の明示・平屋根の放棄・回遊動線・斜面への応答）に従い、スプリットレベル・一本の螺旋動線・垂下梁・折れ板屋根を具体化した。品質24→32、美30→38、感情28→36。

**v3 改訂案（作成スキルの再作成指令を反映）**
```
■ 改訂の骨格：空間の物語・光・構造の正直さを明示。
　・物語：北の入口（低く圧縮された土間）から、朝の台所（東）→昼の中庭（南）→夕の書斎（西）へ
　　と半層ずつ昇り、最後に樹冠の下の南テラスへ「光が強まる順」にたどり着き、また樹に帰る。
　　住まいは一本の螺旋＝「光の暦」になる。
　・光：樹を貫く環状のトップライト（樹冠スロット）を中心に、東西南の三つの開口を
　　冬至・夏至・春分の三断面で寸法を定める。冬の低い陽は北壁を削り、夏の高い陽は庇で遮る。
　・構造の正直さ：垂下梁とオーク柱列を隠さず、耐力の道筋をそのまま見せる。
　　樹は構造図面に「第五柱」として明記され、実際に屋根を支える。
■ 残る問題点：細部の手仕事が粗く、光の切り方に過剰な演出がある。
　材料の経年（雨・霜・樹との出会い）がまだ設計されていない。
```
改訂点: v2報告の指令（空間の物語・光の季節応答・構造の見せ方）に従い、「光の暦」という螺旋の物語を確立し、三断面で光を設計し、垂下梁を隠さず第五柱を図面に明記した。品質32→40、美38→44、感情36→40。

**v4 改訂案（作成スキルの再作成指令を反映）**
```
■ 改訂の骨格：光と材料を断面と部材で確定し、手仕事を仕上げる。
　・樹冠スロットは、夏の正午の日射を簾（杉のルーバー）で遮り、冬の低い陽だけを北壁に落とす。
　　三つの開口に季節の可動庇を設け、「光の暦」を実際に操作できるようにする。
　・材料を敷地から調達して確定する：掘削土による版築（熱マス）、杉の外装、オークの柱梁、
　　樹の足元の玉石。版築が蓄熱し、樹冠スロットが夜に熱を吐く受動的熱環境を成立させる。
　・製材と継手の詳細を詰める。樹と屋根の出会いには、落水線に沿う樋を屋根の折れに一体化し、
　　樹の樹皮を傷めない雨仕舞を完成させる。
```
改訂点: v3報告の指令（光の過剰演出の調整・材料の経年・細部の手仕事）に従い、簾と可動庇で光を実操作可能にし、版築・杉・オーク・玉石という敷地由来の材料を確定し、落水線の樋を屋根の折れに一体化した。品質40→46、美44→48、感情40→44。

**v5 改訂案（作成スキルの再作成指令を反映）**
```
■ 完成形：構造・光・景観・動線が一つの器官として読み取れる。
　・樹の影の軌跡を床に刻む：年間の日陰線を版築の床にラインとして象嵌し、家は「光の暦」そのものを
　　内包する。居室のどこにいても、影の進みで時刻と季節が読める。
　・螺旋の動線は半層ごとに樹に立ち戻り、最後の半階で南テラスに開く。行き止まりは皆無。
　　通風は南斜面の上昇気流を樹冠スロットが抜き、夏の夜は自然換気が家を冷ます。
　・構造は五本目の柱＝樹が全体の中心で、10組のオーク柱列と垂下梁が荷重経路を隠さず示す。
　　版築・杉・オーク・玉石という敷地由来の材料が、経年で同じ色に揃っていく。
　・細部：落水線の樋、簾の間隔、土間から板床への段差、影のラインが触れる床——すべてが
　　同じ原理（樹を中心とした光の暦）から導かれ、余剰がない。
```
改訂点: v4報告の指令（全体の統合・材料の経年一致・詳細の整合）に従い、影の軌跡を床に象嵌して「光の暦」を建物自体に刻み、材料を経年で揃え、細部のすべてを同一原理から導いて完成形に収束させた。品質46→56、美48→54、感情44→46。
