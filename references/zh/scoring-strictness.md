# Scoring Strictness Doctrine — 严格评分标准

本层**有意采取严格的评分**。原因在于，合议的目的不是"表扬好的东西"，而是"看穿真正有价值的东西"。宽松的评分会把平庸的作品抬上高评价，损害合议的判别力。

## 基本原理

1. **高分极少授予。** 60分以上只给证明了"真正的卓越"的作品。75分以上属于例外。85分以上几乎不给予。
2. **平庸会落入低分。** "稳妥但不起眼"的作品落入 20-40 分区。仅凭完成度高并不能得到高分。
3. **标准向严格靠拢。** 包括AI生成在内的日常输出，大部分分布在50分以下。将分布的**中位数设在 30 前后**。也就是说，"普通的好"落在 30-45 分。
4. **危险信号会强力扣分。** 一个严重的危险信号（平庸的表达、情感操控、虚假的新颖等），即使其他维度很好，也会将分数拉低 25-40 分。

## 通用分数带（各评估者共通的标准）

| 带 | 含义 | 频率预期 |
|----|------|-------------|
| 0-10 | 严重缺陷・无价值征兆 | 偶尔给出 |
| 11-30 | 弱。部分逊色 | 较多 |
| 31-50 | 稳妥・平庸。普通能做到 | **最大的人口分布** |
| 51-70 | 真正的好。卓越的征兆 | 略少 |
| 71-90 | 例外。杰出的价值 | 少 |
| 91-100 | 历史性意义 | 几乎不给 |

**判断铁律**：打出分数前，先自问"这真的具有超过50的价值吗？"存疑时取低分。"普通的好"达不到50。

## 应用方法

每位评估者遵循这一准则，严格评分自己的"主要维度"。

- 打出分数前先自问"这真的具有超过60的价值吗？"
- 存疑时取低分。合议的职责是**发现**，而非**认可**。
- 分类（classification）也要从严。只有在证据充分时才给出 `current_success` 和 `innovation`。

## 补充说明

- 这种严格性是为了提高分数的**相对判别力**，并非主张绝对的正确性。
- 它是未来 Meta Value Layer 引入按评估者校准严格度（bias detection）时的基准。
