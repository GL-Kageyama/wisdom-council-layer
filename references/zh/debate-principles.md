# 辩论原则 — 分歧的保存

知慧评议会（Wisdom Council Layer）的核心信念：

> **真理产生于不同观点的碰撞，而非它们的平均化。**

本文件定义了合议如何处理评估者之间的分歧。

## 原则1：分歧不是缺陷，而是输出的一部分

在单一评估者系统中，意见分歧会被当作"噪音"清除。在知慧评议会中，分歧是**一等输出（first-class output）**。

- 当评估者在同一维度上给出相差很大的分数时，这些分数不应被平均化。
- 分歧的**理由**正是理解内容所不可或缺的信息。

## 原则2：全员一致反而可疑

如果10位评估者给出完全相同的分数，可能存在以下情况：

1. 评估者没有独立思考（从众 conformity）
2. 内容极为平庸，任何视角都会得出相同的评价（真正的危险信号）
3. 评估标准存在偏倚

怀疑"全员一致"，是所有评估者的义务。

## 原则3：反驳是评估者的义务

每位评估者都必须预测自己的评价会从其他评估者的视角受到怎样的攻击，并明确地报告这一点。

```
例：
- Originality Evaluator: 独创性高（85分）
- Business Value Evaluator: 市场性低（25分）
- 这一对立本身就是"这部作品虽小众但具开创性"这一重要信息
```

## 原则4：区分冲突的类型

并非所有分歧都具有同等的权重。

| 冲突类型 | 含义 | 合议的处理 |
|-----------|------|-----------|
| **视角差异**（以不同的价值观评价同一事实） | 健康。多元价值的反映 | 保存，两论并列 |
| **事实认知差异**（对同一事物作出不同的解读） | 可能有一方误认 | 重新确认证据，修正误认 |
| **分数波动**（意见几乎一致但数值有所偏差） | 正常变动 | 作为区间记录 |

## 原则5：以数值可视化分歧

Value Report 中应包含 **Disagreement Map**。它用热力图（heatmap）展示各维度上评估者分数的分散度（variance）。

- 分散度大的维度 = 评估者产生分歧的维度 = 信息量最大的维度
- 将该维度的两种论点连同各自的依据一并保存

## 原则6：分歧本身就是价值的征兆

从历史上看，创新性的作品往往是"毁誉参半"的。

```
曾遭嘲笑的绘画作品 → 起初被嘲笑 → 如今被视为杰作
最初被拒绝的前卫作品 → 被拒绝 → 如今成为转折点
```

因此，**评估者激烈分歧的内容，其本身就值得关注**。超越简单的"好/坏"，去评价讨论的质量与深度。

## 原则7：合议不作裁决

合议（编排器 orchestrator）的职责不是"决定正确答案"。

- 从不同价值观中探索可能性
- 为人类判断提供知性辅助基础
- **最终的价值判断是人的责任**（UVIN哲学）

## Phase 3（未来）的扩展

目前采用的是每位评估者在1轮中报告"从他人视角的预测"的方式。在未来的 Debate Engine 中：

- 评估者之间相互阅读对方的评价并**再次反驳**
- 记录经过多轮讨论后观点如何变化
- 允许讨论本身产生新的见解
